## Fetching the originals

Appending `.md` to any of these URLs returns the raw Markdown source on both platform.claude.com and developers.openai.com. This is the cheapest way to read the full page or refresh a condensation.

## Staleness

The claims most likely to go stale, and most likely to be acted on: thinking defaults per model, which API parameters return 400 errors, effort-level recommendations, refusal categories, and deprecation dates. Re-check the sources when a new model ships or when a claim here contradicts what an API returns.
